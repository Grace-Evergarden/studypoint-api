StudyPoint

StudyPoint is an AI-powered study assistant that helps students organize courses, manage lecture materials, and prepare for exams.

Available API Endpoints

GET /api/v1/courses — List accessible courses
GET /api/v1/courses/{id} — Retrieve a course
POST /api/v1/courses — Create a course
PUT /api/v1/courses/{id} — Update a course
DELETE /api/v1/courses/{id} — Delete a course
GET /api/v1/greeting — Display this page
